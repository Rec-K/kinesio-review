# 基础肌动学 · 复习系统

对齐《基础肌动学》第 4 版（北京科学技术出版社 · 曼斯菲尔德 & 诺伊曼 · 祁奇/陆佳妮 译）

## 功能

- **肌肉库**：72 块肌肉，全字段搜索 + 章节筛选
- **反查**：给动作或神经，反查涉及哪些肌肉，并区分**主动肌 / 协同肌**
- **测验**：5 种卡型 + Leitner 间隔重复，弱项优先
- **统计**：掌握度分布、薄弱知识点、卡型强弱

## 技术栈

Vite 8 · React 19 · TypeScript 6 · Tailwind CSS 4 · React Router 7

## 本地开发

```bash
npm install
npm run dev
```

## 数据说明

- 51 块肌肉的起点/止点/神经支配/动作/注释来自教材原文
- 24 块含教材「注释」栏（触诊指导）
- 其余为通行的标准解剖学表述
